# Obsidian Vault Template

A ready-to-use Obsidian vault based on my post [How to actually use Obsidian](https://anguswww.github.io/how-to-actually-use-obsidian).

It includes:

- **Maps:** category notes, built with Dataview, that list every note linked to them.
- **Templates:** for default notes, daily notes, and maps, using Templater.
- **Folders:** `Attachments`, `Daily Notes`, `Maps`, and `Templates`. Everything else stays unfoldered.

## Usage

1. Download the latest release and open the folder as a vault in Obsidian.
2. When asked, choose **Trust author and enable plugins**.
3. Open `Start Here.md`.
