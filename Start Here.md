**Welcome to your vault!** This is a template based on [How to actually use Obsidian](https://anguswww.github.io/how-to-actually-use-obsidian). The post gives some guidelines that I recommend following, but they aren't strict rules. If something doesn't work for you, feel free to organise your notes differently.

## 🧭 Navigation & Setup

### 🏁 Getting Started

1. When Obsidian asks whether to trust this vault's plugins, choose **Trust author and enable plugins**. Dataview and Templater power the maps and templates.
2. Rename [[Example Map]] to your first real topic, then make more maps by copying [[Map Template]] into the the Maps folder.
3. Once you have your bearings, feel free to delete this note and the `README`.
### 📂 Folders

The left sidebar shows your notes and folders.
 - `Attachments` stores images, pdfs, and other files that you attach or embed in your notes.
 - `Daily Notes` stores notes timestamped to each day. Create daily notes through `Cmd/Ctrl`+`P`→`Daily Notes: Open today's daily note`.
- `Maps` stores map notes for your categories or topics. By default it contains a `Daily Notes` map, which lists all your daily notes, and an `Example Map` which you can rename or remove.

You should avoid putting notes into folders. I explain why in [How to actually use Obsidian](https://anguswww.github.io/how-to-actually-use-obsidian).
### 🗺️ Maps

Maps correspond to different categories for your notes. You add notes to these categories by linking to them in the `categories` property at the top of the note. You can do this by pressing `[[` in the categories field, and searching for the corresponding map.

You can make maps for any topic you want. Some good examples are:
- A topic you are interested in writing about or researching,
- A project you are working on
- A goal you are working towards
- A class you are taking
- Anything you want

Notes can and should be put into multiple of these categories, not just one.
### 🛟 Guidelines
These are some guidelines for writing notes.
- Use internal links `[[like this]]` as much as you can. Obsidian is great at drawing useful ideas together
- Mostly avoid graph view (`Ctrl/Cmd`+`G`) for navigating your notes. This gets shown a lot in tutorials because it's a very visually striking way of showing an Obsidian vault but it isn't really useful as anything other than a cool novelty.
- Mostly avoid plugins that majorly overhaul parts of Obsidian.
- Don't install any AI plugins. To use AI in your vault, just point Claude Code, Codex, or whatever other agent at your vault directory.
- If you use AI, create an AI folder to contain any LLM outputs, and an AGENTS.md or CLAUDE.md saying to use it.
### 🛠️ Shortcuts

Most editing shortcuts are what you would expect if you know markdown.

- `Cmd/Ctrl`+`P` - command palette
- `Cmd/Ctrl`+`O` - quick switcher (open any note)
- `[[` - link a note
- `![[` - embed a note or image

### ☁️ Cloud syncing and backups
Cloud syncing and backups are not set up by default.
- [Obsidian Sync](https://obsidian.md/sync) is simple to set up but costs $4/month, which funds Obsidian's development. I have never used it but haven't heard anything bad about it.
-  [Git Sync](https://community.obsidian.md/plugins/git-obsi-sync) is harder to set up, but is free.
#### Git
- [Git Sync Plugin](https://community.obsidian.md/plugins/git-obsi-sync) - Use this on Mac, Linux, or Windows.
- [GitSync App](https://gitsync.viscouspotenti.al/) - Use this on iOS or Android.

> [!warning]
If you cloned this as a Git repository instead of downloading it from the releases page, you might need to delete the `.git` hidden folder.

To set up the Git Sync plugin and the GitSync phone app, **which are similarly named but separate things**, follow [this tutorial](https://viscouspotenti.al/posts/gitsync-all-devices-tutorial).
### 🎨 Themes
No custom theme is set. You can find themes either in settings or [online](https://community.obsidian.md/search?type=theme). I use the [Minimal](https://community.obsidian.md/themes/minimal) theme with the Flexoki colour scheme, but there are many good options.
### 🪴 Digital Gardening
To set up a [Digital Garden](https://anguswww.github.io/digital-gardening) I would recommend [Quartz](https://quartz.jzhao.xyz/), with [Quartz Syncer](https://community.obsidian.md/plugins/quartz-syncer) publishing to [Github Pages](https://docs.github.com/en/pages). You could also use [forestry.md](https://forestry.md/) for easier setup, but it is less flexible and requires a subscription to publish more that 30 times per month.
